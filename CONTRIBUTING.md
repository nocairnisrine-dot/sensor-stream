# Contribuer à SensorStream

## Branches
- main = production, develop = intégration
- feature/<nom> part de develop
- release/<x.y.z> part de develop
- hotfix/<x.y.z> part de main

## Commits conventionnels
feat:, fix:, docs:, test:, refactor:, chore: + message à l'impératif
Exemple : feat(buffer): add circular buffer

## Pull Requests
- Titre : [feature/buffer] Description
- Corps : ce qui change, comment tester, Closes #<issue>
- L'auteur ne fusionne jamais sa propre PR

## Ordre de relecture
Le membre n relit le membre n+1, le dernier relit le premier.
